TrimUI Brick kernel reconstruction -- provisional
================================================

This tree is a partial reconstruction, not a recovered vendor source release.
Stock-equivalent behavior, full source parity and hardware boot tests remain
incomplete. The commit order is a reconstruction history, not the original
vendor's patch order.

Stock firmware: trimui/firmware_brick v1.1.1-20251126, TG3040 Brick.
ZIP SHA256: 488db02176e81ad4fdcf9e0bb4dbf406c883199f5b3521445e038bf81c8916ef
Kernel: Linux 4.9.191, #860 SMP PREEMPT, Nov 26 03:43:02 UTC 2025.
Original compiler: OpenWrt/Linaro GCC 7.4.1 (7.4-2019.02).
Compiler tested here: TRIMUI-published Linaro GCC 7.5.0.

Build
-----

Use an AArch64 GCC cross toolchain. Set an absolute output path:

  make ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- O=/path/to/output \
       trimui_brick_reconstructed_defconfig
  make ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- O=/path/to/output \
       -j16 Image modules dtbs
  make ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- O=/path/to/output \
       M="$PWD/modules/gpu/img-rgx-1.19" PVR_SYSTEM=sunxi_a133 \
       CONFIG_DRM_IMG_ROGUE=m ODYSSEY_CAPTURE=0 -j16 modules

The DTB is arch/arm64/boot/dts/sunxi/trimui-brick-stock.dtb in the output tree.
The original full IKCONFIG is preserved as trimui_brick_stock_defconfig.
It is evidence, not a currently reproducible stock configuration.

Known incomplete areas
---------------------

* NAND: public BSP lacks common1/lib and nftl_v8.S; disabled in candidate.
* Stock ALPU/Arelink, TCS4838, exFAT and two additional LCD driver options.
* XRadio rate-control config and remaining driver differences.
* Vendor LED animation/sysfs, motor and speaker integration.
* Vendor framebuffer expansion and complete charging/PMIC behavior.
* Full GPU data-layout/firmware ABI equivalence.
* Not every kernel function/data object has been compared.

The reconstructed panel tables compile byte-identically to all five stock
tables. This does not validate display operation. The lcd_model_name setup
copy is intentionally bounded; stock used strcpy. Recovered 120-byte gc9702c
counts are retained, including reads into the following table entry.

Candidates exist for all 22 module filenames shipped in the firmware.
Static function-code matches do not establish whole-module/data equivalence.
No bootable replacement firmware or deployable stock-equivalent image has
been established. No hardware has been flashed or tested.
