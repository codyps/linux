TrimUI Brick kernel reconstruction
=================================

This is a reconstruction, not the manufacturer's original source release.
The normalized defconfig reproduces every enabled stock configuration value.
Image, modules and the recovered DTB build, including candidates for every
shipped module filename. Hardware boot and complete behavioral equivalence
remain unverified. Commit order is reconstruction history, not vendor history.

Stock: trimui/firmware_brick v1.1.1-20251126, original TG3040 Brick.
ZIP SHA256: 488db02176e81ad4fdcf9e0bb4dbf406c883199f5b3521445e038bf81c8916ef
Kernel: Linux 4.9.191, #860 SMP PREEMPT, Nov 26 03:43:02 UTC 2025.
Original compiler: OpenWrt/Linaro GCC 7.4.1 (7.4-2019.02).
Compiler tested here: TRIMUI-published Linaro GCC 7.5.0.

Build
-----

Use an AArch64 GCC cross toolchain and an absolute output path:

  make ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- LOCALVERSION= O=/path/to/output \
       trimui_brick_defconfig
  make ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- LOCALVERSION= O=/path/to/output \
       -j16 Image modules dtbs
  make ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- LOCALVERSION= O=/path/to/output \
       M="$PWD/modules/gpu/img-rgx-1.19" PVR_SYSTEM=sunxi_a133 \
       CONFIG_DRM_IMG_ROGUE=m ODYSSEY_CAPTURE=0 -j16 modules

DTB: arch/arm64/boot/dts/sunxi/trimui-brick-stock.dtb in the output tree.
trimui_brick_stock_defconfig preserves the full original IKCONFIG as evidence.
trimui_brick_reconstructed_defconfig is a compatibility copy of the normalized
trimui_brick_defconfig. The companion workbench build wrapper checks all stock
configuration values before building in its default stock mode.
Pass LOCALVERSION= explicitly to suppress Git's '+' suffix and preserve the
shipped 4.9.191 module vermagic. This does not change the stock configuration.

Reconstruction evidence
-----------------------

* All five panel command arrays match the original bytes after compilation.
* TCS4838 MFD/regulator tables, pointers and register settings match stock.
* Arelink is usable reconstructed C, not decompiler pseudocode: 754 comparisons
  against emulated stock code cover cipher output, framing and EEPROM commands.
* LED callbacks preserve stock parse failures, buffer overruns, NULL/error
  regulator calls and sparse output writes. 693 compiled callback cases, 720
  transfer cases and 202 daemon cases (3310 iterations) match emulated stock.
  Relative LED state layout and driver link order are recovered; absolute
  layout and every live adjacent overflow victim are not yet matched.
* 269 compiled panel/effect cases include oversized copies and effect writes
  beyond declared arrays. These execute only in mapped emulated storage.
* NAND IDs were recovered into C: 63 descriptors, eleven manufacturers, with
  recursive comparison of every table byte and referenced string.
* The published NAND translation-layer assembly was already in the baseline;
  its out-of-tree build rule was broken. It is not recovered original C.
* The inode i_sequence backport restores the 560-byte stock inode layout.
  All 414 shared structures sampled from vin_io DWARF match member layouts.
* Bluetooth UART/H4/coexistence matches all 74 compared instruction bodies.
* AXP2202 battery/USB/GPIO power code matches all 46 uniquely comparable
  instruction bodies. Battery SOC passes 5632 emulated comparisons, including
  the 3450 mV median-voltage threshold. IRQ names/callbacks and property IDs
  pass 24 recursive data checks. These checks do not validate a physical PMIC.
* GC2590 and OV5648 each match all 14 comparable function bodies and 11 selected
  data objects, including register arrays, window modes and callback tables.
* GPU reconstruction restores the generic handle backend, memory tests,
  display-class ABI, Configure2 bridge and 63-byte annotation limit. All 141
  sampled display-class and 133 sampled memory layouts match stock DWARF.
  Recovered A133 platform, DVFS, DMA, heap configuration, command-queue context,
  memory mapping and client-connect initialization. 1958 of 2063 comparable
  pvrsrvkm bodies and all 18 dc_sunxi bodies match raw code/relocations.
  Separate emulated checks cover configuration, power and memory lifecycles;
  The Linaro GCC 7.4.1 candidate gives 1974/2063 raw matches; the other 89
  classify as diagnostic-line differences. This is not the original customized
  OpenWrt compiler. Every referenced data object and hardware path is not yet
  verified.
* Video capture now matches all 86 vin_io and 554 vin_v4l2 comparable bodies.
  Four format tables match recursively, including RGB888/BGR888 descriptors.
* Wi-Fi serial-derived MAC addressing and AP restart diagnostics are restored.
  1060 emulated MAC cases and 8336 arithmetic/CMAC/spill cases match stock.
  The CMAC checks use a cipher stub and do not verify the AES primitive.
* Public exFAT matches every uniquely comparable function body after restoring
  inode layout. Static comparison accounts for address relocation instructions;
  it does not establish equality of every referenced data object.

The companion workbench repository contains scripts, original artifact hashes,
Ghidra pseudocode, detailed comparison results and the exported commit series.
No manufacturer source files were inferred from filenames alone.

Limits and reconstruction policy
--------------------------------

Preserve shipped behavior even where it is erroneous. Comments marked TODO
identify fixes that must be separate from this reconstruction. The panel's
unbounded strcpy, unchecked LED buffers and scale table, failed-parse side
effects, invalid regulator calls and incomplete teardown are intentional stock
compatibility. Emulated tests do not prove every manifestation of undefined
behavior or concurrent access. Arelink C reorganizes implementation and private
AES routines; complete equivalence has not been established.

Some GPU and other kernel code/data differences remain. Wi-Fi instruction
residuals are separately classified and tested; whole-driver equivalence and
every referenced video-capture object have not been established.
Camera sensor and PMIC checks above cover selected functions and tables, not
every referenced object. Stock battery SOC handling after a failed voltage
sample can read uninitialized values; that undefined case is excluded from the
differential tests and has not been silently changed.
Missing global names also include private AES routines replaced by reconstructed
C and unused stock helpers; symbol inventory is not semantic equivalence.
The compiler differs from stock. Not every local function or data object has
been compared. No physical display, audio, input, charging, suspend, storage,
radio or GPU test has run. No device has been flashed. A stock-configured build
must not be described as a hardware-validated stock-equivalent firmware image.
